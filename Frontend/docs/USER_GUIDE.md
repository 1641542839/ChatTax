## 快速开始

ChatTax 是一个智能税务清单生成工具，通过 AI 对话帮助您收集税务信息并自动生成个性化的税务文件清单。

### 系统要求

- 现代浏览器（Chrome 90+, Firefox 88+, Safari 14+, Edge 90+）
- 稳定的网络连接
- 启用 JavaScript

### 访问网站

打开浏览器访问：`http://localhost:3000`（开发环境）

## 注册和登录

### 创建账户

1. 点击右上角 **"注册"** 按钮
2. 填写注册信息：

   - 用户名
   - 密码（至少 8 个字符）
   - 全名（可选）
3. 点击 **"注册"** 完成

**方式一：邮箱登录**
1. 点击 **"登录"** 按钮

**方式二：Google 快捷登录**
1. 点击 **"使用 Google 登录"**
2. 选择您的 Google 账户
3. 授权后自动登录

点击右上角头像 → **"退出登录"**

## 三种生成模式

ChatTax 提供三种清单生成方式，适合不同使用场景：

### 模式 1：快速表单（推荐新手）

**适用场景**：您清楚自己的税务情况，想要快速生成清单

**操作步骤**：
1. 进入 **"生成清单"** 页面
2. 选择 **"快速表单"** 模式
3. 填写表单信息：
   - 报税身份（单身/已婚联合/户主等）
   - 年收入范围
   - 是否有受抚养人
   - 州/地区
   - 特殊情况（自雇/投资/房产等）
4. 点击 **"生成清单"**

**优点**：
- ✅ 最快速（2-3 分钟）
- ✅ 结构清晰
- ✅ 适合情况简单的用户

### 模式 2：引导式对话（推荐不确定的用户）

**适用场景**：不确定需要填写什么信息，需要 AI 逐步引导

**操作步骤**：
1. 进入 **"生成清单"** 页面
2. 选择 **"引导式对话"** 模式
3. 按照 AI 提问回答问题：
   - 第 1 步：选择报税身份
   - 第 2 步：选择收入范围
   - 第 3 步：是否有受抚养人
   - 第 4 步：选择州/地区
   - 第 5 步：就业类型
   - 第 6 步：投资情况
   - 第 7 步：抵扣项目
   - 第 8 步：额外信息
   - 第 9 步：完成并生成
4. 每步完成后自动进入下一步
5. 全部完成后自动生成清单

**优点**：
- ✅ 无需了解税务术语
- ✅ 逐步收集信息
- ✅ 不会遗漏重要项目
- ✅ 显示进度条

**示例对话流程**：

```
AI: 您的报税身份是什么？
您: [选择] 已婚联合报税

AI: 您的预估年收入是多少？
您: [选择] $75,000 - $100,000

AI: 您有未满 17 岁的受抚养人吗？
您: [选择] 是
AI: 有几位？
您: [输入] 2

... (继续回答其他问题)
```

### 模式 3：自由对话（推荐高级用户）

**适用场景**：想要自然对话描述税务情况，让 AI 自动提取信息

**操作步骤**：
1. 进入 **"聊天"** 页面
2. 用自然语言描述您的情况
3. AI 会自动提取税务信息
4. 右上角显示信息收集进度
5. 当信息完整度 ≥ 60% 时，显示 **"生成清单"** 按钮
6. 点击按钮生成清单

**优点**：
- ✅ 最自然的交互方式
- ✅ 可以随时补充信息
- ✅ AI 智能理解复杂情况
- ✅ 支持多轮对话

**示例对话**：

```
您: 你好，我需要准备 2024 年的税务文件

AI: 您好！我会帮您生成个性化的税务清单。请告诉我您的基本情况。

您: 我是已婚联合报税，有两个 10 岁以下的孩子，年收入大约 8 万美元

AI: 好的，我记录了以下信息：
   - 报税身份：已婚联合报税 ✓
   - 受抚养人：2 位 ✓
   - 收入范围：$75,000 - $100,000 ✓
   
   请问您住在哪个州？

您: 加州

AI: 明白了。请问您有以下情况吗？
   - 自雇收入
   - 投资收入（股票、债券等）
   - 房产出租
   - 教育支出

您: 我有一些股票投资，每年分红大概 3000 美元。还有孩子的教育费用

AI: 收到！我已更新信息：
   - 投资收入：有 ✓
   - 教育支出：有 ✓
   
   [信息完整度：75%]
   [显示"生成清单"按钮]
```

## 使用聊天功能

### 开始对话

1. 点击左侧菜单 **"聊天"**
2. 系统自动创建新会话
3. 在输入框输入问题或描述情况
4. 按 **Enter** 发送（Shift+Enter 换行）

### 查看信息提取进度

对话过程中，右上角会显示：
- **信息完整度**：0-100%
- **已提取字段**：如报税身份、州等
- **缺失字段**：还需要补充的信息

### 智能生成按钮

当信息完整度 ≥ 60% 时：
- 显示浮动的 **"生成清单"** 按钮
- 按钮显示当前完整度百分比
- 点击按钮即可生成清单
- 自动跳转到清单详情页

### 意图识别标签

AI 会自动识别您的问题类型并显示标签：
- 🔵 **解释说明**：您在询问税务术语或文件说明
- 🟢 **新增信息**：您提供了新的税务信息
- 🟠 **更新请求**：您要求更新清单
- ⚪ **一般对话**：普通交流

### 实用对话示例

**询问文件说明**：
```
您: W-2 表格是什么？
AI: [解释说明标签] W-2 表格是雇主提供的工资和税务报告...
```

**补充新信息**：
```
您: 对了，我去年还买了一套出租房
AI: [新增信息标签] 好的，我已记录您有房产出租收入...
您会需要以下额外文件...
```

**请求更新清单**：
```
您: 我的情况有变化，能更新清单吗？
AI: [更新请求标签] 当然可以！请告诉我有什么变化...
```

## 管理会话

### 查看会话列表

左侧边栏显示所有聊天会话：
- 会话 ID（前 8 位）
- 最后更新时间
- 消息数量
- 是否已生成清单（✓ 图标）

### 切换会话

点击会话卡片即可切换到该会话，右侧显示对话历史

### 创建新会话

点击左上角 **"+ 新建"** 按钮创建新会话

### 删除会话

1. 点击会话卡片右侧的 **垃圾桶图标**
2. 确认删除
3. 注意：删除后无法恢复

### 会话自动保存

- 所有对话自动保存到数据库
- 刷新页面后会话不丢失
- 可在多个设备间同步（需登录）

## 查看和管理清单

### 查看清单列表

1. 点击 **"我的清单"** 菜单
2. 显示所有已生成的清单
3. 按创建时间排序

### 查看清单详情

点击清单卡片进入详情页，包含：
- 清单标题
- 生成模式标签
- 分类列表（个人信息、收入文件、抵扣项目等）
- 每个项目的详细说明
- 完成状态复选框

### 标记项目完成

- 点击项目前的 **复选框** 标记为已完成
- 自动保存
- 可随时取消标记

### 在清单中提问（智能功能）

清单详情页右下角有 **聊天按钮**：

1. 点击聊天按钮打开浮动面板
2. 可以询问任何关于清单的问题：
   ```
   您: 1099-MISC 是什么？在哪里获取？
   AI: [解释] 1099-MISC 是非雇员报酬表格...
   ```

3. 提供新信息时，AI 会提示更新清单：
   ```
   您: 我还有自雇收入
   AI: [检测到新信息] 
   [弹出提示] 是否更新清单以包含自雇相关文件？
   ```

4. 点击 **"更新清单"** 按钮重新生成

### 导出清单

点击 **"导出 PDF"** 按钮（即将推出）

### 删除清单

1. 点击清单详情页右上角 **"删除"**
2. 确认删除

## 常见问题

### Q1: 三种模式有什么区别？

**快速表单**：
- 时间最短（2-3 分钟）
- 适合清楚自己情况的用户
- 一次性填写所有信息

**引导式对话**：
- 时间适中（5-10 分钟）
- AI 逐步提问，不会遗漏
- 适合不熟悉税务的用户

**自由对话**：
- 时间灵活
- 自然语言交流
- AI 自动提取信息
- 可随时补充

### Q2: 如何知道收集了多少信息？

自由对话模式中：
- 右上角显示 **信息完整度百分比**
- 60% 以上即可生成清单
- 80% 以上为最佳状态

### Q3: 生成的清单可以修改吗？

可以！有两种方式：
1. **直接修改**：在清单详情页标记完成状态
2. **重新生成**：在聊天面板补充信息后，点击"更新清单"

### Q4: 我的对话会保密吗？

是的：
- 所有数据加密传输（HTTPS）
- 对话历史仅您可见
- 不会分享给第三方
- 可随时删除会话

### Q5: 一个会话可以生成多个清单吗？

不可以。每个会话对应一个清单，但您可以：
- 创建多个会话
- 每个会话生成不同的清单
- 在清单中继续对话并更新

### Q6: 忘记之前的对话怎么办？

不用担心：
- 所有会话自动保存
- 左侧边栏查看历史会话
- 点击会话卡片即可恢复

### Q7: 如何获得更准确的清单？

**提示**：
1. **详细描述情况**
   ```
   ✅ 好: "我是软件工程师，年收入 9 万，有妻子和 2 个孩子，
         去年买了房，有房贷利息，还投资了 IRA 账户"
   
   ❌ 差: "我需要报税"
   ```

2. **提供具体数字**
   ```
   ✅ 好: "两个孩子，5 岁和 8 岁"
   ❌ 差: "有孩子"
   ```

3. **说明特殊情况**
   ```
   ✅ 好: "我有一套出租房，每月租金 $2000"
   ✅ 好: "去年换过一次工作"
   ✅ 好: "有股票交易，亏损约 $3000"
   ```

### Q8: AI 能理解中英文混用吗？

可以！ChatTax 支持：
- 纯中文
- 纯英文
- 中英文混用

示例：
```
您: 我是 married filing jointly，有两个 kids
AI: ✓ 理解：已婚联合报税，有 2 位受抚养人
```

### Q9: 如果 AI 理解错误怎么办？

直接纠正即可：
```
您: 我有两个孩子
AI: 记录了：2 位受抚养人

您: 不对，是 3 个孩子
AI: 已更新：3 位受抚养人 ✓
```

### Q10: 生成的清单包含哪些内容？

标准清单包含以下分类：

1. **个人信息**
   - 社会安全号 (SSN)
   - 出生日期
   - 联系方式

2. **收入文件**
   - W-2（工资收入）
   - 1099 系列（其他收入）
   - 自雇收入记录

3. **抵扣项目**
   - 房贷利息
   - 慈善捐赠
   - 医疗费用
   - 教育支出

4. **税务抵免**
   - 儿童税收抵免
   - 教育抵免
   - 退休储蓄抵免

5. **州税文件**（根据所在州）

6. **其他文件**（根据个人情况）
